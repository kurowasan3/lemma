# 推薦のストレステスト（v0.20）

`node tools/simulate_recommend.mjs [日数=60] [seed=1] [学習者]` で再現できる。テスト（`tests/recommend.test.mjs`）は40日分で次を確かめる：毎回、復習以外の問題が2問以上／選んだ難易度の外から新しい問題を出さない／復習以外で3日以内に同じ問題を出さない／1回で同じ分野が半分を超えない／同じ解法が解法の推薦の3割を超えない／推薦の理由と選んだ規則が一致する（選んだ時点の状態で、復習の時期・要復習の解法・未学習の解法・転用の対象であったか）。

## 分かったことと、v0.20 で直したこと

- v0.19 では、1分野に偏った過去の記録・大量の復習待ちがあると、復習が1分野で埋まり、1回の88%が同じ分野になった → 復習も1つの分野から1回の半分まで、復習以外と合わせても半分まで。
- 要復習の解法が同じ解法から毎回出続けうる → 直近24時間にその解法の問題を解いていれば次の解法へ。
- 復習待ちは、毎日8問・新しい問題2〜3問では、多くの学習者で少しずつ増える（毎日1回で60日後に約90問）。これは1日に解ける量に対して新しい問題を足し続けるためで、新しい学習の枠を0にすれば止まるが、それでは新しい問題が出なくなる。新しい学習の枠を残し（たまっているときは2問）、たまった分は「復習だけ」と定着度の「次にやること」で知らせる。
- 難易度を広く選ぶと、解法の推薦（未学習・要復習の解法）は選んだ範囲でやさしい問題から出すため、易しい問題の割合が高くなる（毎日1回で難易度0が約4割）。基礎をくり返す方針に合っているので変えていない。
