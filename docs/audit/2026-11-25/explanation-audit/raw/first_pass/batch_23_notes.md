## 独立解答と保存済み答案の食い違い・表記差

### III-DIF-380 (2)（C）
- 保存済み：「γ>0 ⟺ ab<e」。独立解答：「ab<e（2個となる条件と合わせれば ab<e かつ max(a,b)>1）」。
- 検証：f''≧0，a>1（対称性）で f' は狭義増加，f'(m)=0 となる m が一意。f'(0)=log(ab)-1。ab<e なら f'(0)<0 で m>0，f(m)<0，零点は 0 と γ>m>0。ab>e なら γ<m<0。保存済みの論証は正しい。
- 問題点：前提「解がちょうど2個」（a>1 または b>1，かつ ab≠e）を外すと，ab<e だけでは a,b≦1（解1個）も含む。最終答案に前提が明示されていないので C とした。
