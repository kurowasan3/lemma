# 独立解答の方法・確信度

## 作成手順と独立性

1. 統括者が `content/problems/*.json` から `statement` だけをスクリプトで抜き出し，254問を26バッチに分けた（答え・解説・解法情報は抜き出していない。小問番号は統合監査の `subproblem_summary.csv` から番号だけを使用）。
2. 各バッチを，新しいエージェント（保存済みの答え・解説・過去の監査を見ていない）に1つずつ割り当てた。手順書の要点：問題文と手順書以外は開かない／できるだけ解析的に解く／数値計算は検算・探索補助に限り，証明の代わりにしない／有限探索で一般式を推定したら未証明と明記／確信度を正直に書く。
3. 各エージェントの出力は統括者が書き換えずに連結した（`independent_solutions.md`）。
4. このファイルと `independent_solutions.md` を，保存済み解説を開く前にコミットで凍結した。

## 注意

- 確信度は各エージェントの自己申告。666小問のうち「高」は 664，「中」は 2，「低」は 0。自己申告の「高」は検証済みを意味しない。
- 「数値計算・プログラム」欄が「あり」でも，各エージェントは論証を解析的に完結させたと申告している。照合段階では，この申告に頼らず保存済み解説を検証する。
- 統括者自身の汚染：B-SEQ-299 の保存済み解説冒頭を前の作業で表示している。独立解答は別エージェントが作成したので独立解答の独立性には影響しないが，記録として残す。
