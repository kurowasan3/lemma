# 独立解答の作成手順（解説監査・第1段階）

あなたは、大学受験数学の問題について「保存済みの答え・解説を一切見ずに」独立した解答と論証を作る担当です。

## 絶対に守ること（独立性）

- 読んでよいのは、担当バッチのファイル `/tmp/expl-indep/batches/batch_NN.md` と、この手順書だけ。
- 次は**開かない・一覧も取らない・検索しない**：
  - `/home/claude/lemma/` 以下すべて（リポジトリ。保存済みの答え・解説・過去の監査記録がある）
  - `/tmp/blind-dual-rest/`、`/tmp/blind-work/`、`/tmp/agg/`、`/tmp/expl-cmp/`（過去の解答や照合結果がある）
  - 他のバッチの出力 `/tmp/expl-indep/out/` の自分以外のファイル
  - インターネット上の解答（WebSearch / WebFetch は使わない）
- もし誤って上記を見てしまったら、その問題IDと見たものを出力ファイルの末尾「独立性の記録」に正直に書く。

## 作業

- 計算用のスクリプトは `/tmp/expl-indep/work/batch_NN/` に置く（なければ作る）。Python は `python3 -I` で実行。sympy/numpy/scipy/mpmath は使える（なければ `pip install --break-system-packages`）。
- 各問題・各小問を**できるかぎり解析的に**解く。証明問題は自分で証明を組み立てる。
- 数値計算・プログラムは検算・探索の補助に使ってよいが、証明の代わりにしない。
  - 有限範囲の探索や数値から一般式・値を推定した場合は、そのことを明記し、一般の証明ができていなければ「未証明」と書く。
- 境界値・退化ケース・場合分けの漏れ・必要十分の向きに注意する。
- 確信度は正直に：高（論証が完結し検算も一致）／中（論証に未確認の箇所がある）／低（推定や未証明が残る）。
- 1問に時間をかけすぎて他を落とさないこと。ただし手を抜いて「証明」とだけ書くのは不可。証明問題も骨子ではなく、受験生が再現できる程度の論証を書く（長くなりすぎる場合は要点を落とさず簡潔に）。

## 出力

`/tmp/expl-indep/out/batch_NN.md` に、次の書式で**バッチ内の全問題・全小問**を書く（小問番号はバッチファイルの「小問：」行のとおり。小問がない問題は「全体」）。

```
## <問題ID>

### (1)
- 種別: 値 / 証明 / 値と証明
- 最終答案: <値・式・集合・範囲など。証明なら「証明」と主張の要約>
- 解法: <方針を1〜3行>
- 証明・計算過程:
  <論証。数式は LaTeX で>
- 使用した定理・公式: <…>
- 場合分け: <…／なし>
- 境界・例外の確認: <端点・除外点・退化ケースなど何を確認したか>
- 数値計算・プログラム: なし / あり（目的と範囲：…）
- 未証明の点: なし / <…>
- 確信度: 高 / 中 / 低

### (2)
...
```

最後に次の節を必ず書く：

```
## 独立性の記録
- 参照したファイル: <バッチファイルと手順書のほかに開いたものがあれば列挙。なければ「なし」>
```

終わったら、出力ファイルのパスと、確信度「低」の小問・未証明の点がある小問の一覧だけを短く報告する。
