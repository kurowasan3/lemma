# v0.29.3：新しい254問の入力用の答え

- **作り方**：既存の手順 `tools/build_input_answers.sh` をそのまま使った。
  1. 元の「答え」（LaTeX）から下書きを作る（make_input_answers.py）。
  2. アプリの採点で読めるか確かめる（check_answers.mjs）。
  3. 書き方を整える（pretty_specs.mjs）。
  4. SymPy で元の答えと値を独立に照合する（crosscheck_answers.py）。
  5. 合わない小問は「記述」（自己採点）に戻す。
- **記録**：
  - `specs.json`：手順の出力そのまま。
  - `input_answers.csv`：問題ごとの元の答え・入力用の答え・自己採点の理由。
