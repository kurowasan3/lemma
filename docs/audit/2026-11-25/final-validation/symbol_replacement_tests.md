# 記号の付け替え（B-SEQ-342）の回帰検査

`symbol_replace.py` の結果。B-SEQ-342 の修正で，1回目の正規表現が「d_mb_n」の b_n を取りこぼした（前が英字のため）。
LaTeX の命令名（`\` の後の英字）を読み飛ばす字句解析版を作り，これまでの2つの正規表現と比べた。

| ケース | 入力 | 期待 | 字句解析版 | 正規表現 v1（1回目） | 正規表現 v2（2回目） |
|---|---|---|---|---|---|
| 単独の b_n | `$b_n$` | `$d_n$` | ✓ | ✓ | ✓ |
| 積の2つ目の因子（前が英字 m） | `$d_mb_n$` | `$d_md_n$` | ✓ | ✗ `$d_mb_n$` | ✓ |
| 別の記号との積 | `$a_nb_n$` | `$a_nd_n$` | ✓ | ✗ `$a_nb_n$` | ✓ |
| 波括弧の添字 | `$b_{n+1}$` | `$d_{n+1}$` | ✓ | ✓ | ✓ |
| 命令 \beta の添字（対象外） | `$\beta_n$` | `$\beta_n$` | ✓ | ✓ | ✓ |
| 添字のあとにべき | `$b_n^2$` | `$d_n^2$` | ✓ | ✓ | ✓ |
| 分数の中 | `$\frac{b_n}{a_n}$` | `$\frac{d_n}{a_n}$` | ✓ | ✓ | ✓ |
| 添字 n-1 | `$b_{n-1}$` | `$d_{n-1}$` | ✓ | ✓ | ✓ |
| ディスプレイ数式の中・\qquad の直前 | `\[⏎b_mb_n=b_pb_q\qquad(**)⏎\]` | `\[⏎d_md_n=d_pd_q\qquad(**)⏎\]` | ✓ | ✗ `\[⏎d_mb_n=d_pb_q\qquad(**)⏎\]` | ✓ |

- 字句解析版はすべて合格。v1 は積の2つ目の因子を取りこぼす（今回の不具合）。v2 は今回の解説では正しく動いたが，名前が b で終わる英字の命令（例 `\sub`）の中まで書き換える欠陥がある。
- 今後同様の記号変更をするときは，`rename_subscripted`（字句解析版）を使い，`changed_only_at` で「意図した置換箇所以外に差がないこと」を確かめる。
