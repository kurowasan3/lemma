# 新規254問のうち161問：答えを見ない解き直しと照合（AIによる確認）

日付: 2026-11-25
対象: v0.29.2 で追加した254問のうち、v0.29.3 で入力用の答え（grading）を付けた161問（レベル3: 11問、レベル4: 124問、レベル5: 26問）

## これは何か

保存されている答え（`answer`）を見ずに、問題文だけから解き直した結果と、保存されている答えを照合した記録である。

- 解いたのは AI（Claude）であり、**人による確認ではない**。
- `content/quality/human.json` と `content/quality/auto.json` は変更していない。
- 問題データの `quality.checks.dual` も変更していない。この値は管理表の「検証:二重解答」列から来る作成時の申告である（docs/quality.md）。今回の結果をそこに反映するかどうかは別途判断する。
- 問題文、答え、解説、ID、タグ、学習履歴は変更していない。

## 手順

1. 161問を難易度順に並べ、問題文（`statement.tex`）だけを表示して解いた。
2. 解いた答えは `independent_answers.md` に書き、そのあとで保存されている答えを表示した。照合前に自分の答えを書き換えていない。
3. 手計算だけで済まないものは、次の方法で答えを出した。どの問題でどれを使ったかは `results.csv` の「解き方」列にある。
   - 総当たり（数え上げ問題など）
   - SymPy による記号計算
   - 数値計算（最大・最小や極限の値の確認、領域の形の推定）
4. 最終的な答え（値・式・個数・範囲など）を照合した。

## 結果

この記録は「解答が正しいことを証明した」ものではない。AI が答えを見ずに解き直し、最終的な答えが一致することを確かめた記録である。

分類の意味:

- **A**: 解析的に導いて一致
- **B**: 数値計算や範囲を限った探索で答えを決めて一致
  - A と同じ強さの検証としては扱わない
  - 境界、例外点、一般の n での成立は追加確認の余地がある
- **C**: 表記や形式は違うが、数学的に同値
- **D**: 不一致。人による確認が必要

| 分類 | 問題数 |
|---|---|
| A | 137 |
| B | 20 |
| C | 4 |
| D | 0 |

総当たりのうち、有限の全ケースを調べ尽くしたものは A に入れた。B にしたのは、数値で値や形を見つけたもの、または範囲を限った探索に頼ったものである。各問題の理由は `results.csv` のメモ欄にある。

再確認を経て一致としたものが1問ある。

- **C-CUR-458 (2)**（分類 B）
  - 最初の解き直しでは、数値探索をもとに端点を含めた範囲を答えた。
  - 保存されている答えは端点を含まない。
  - 端点を調べ直すと、最小値を与える点 P が Q と一致してしまい、「P は Q と異なる」という条件に反する。
  - したがって保存されている答えが正しく、誤っていたのは解き直しのほうである。

## 確認していないこと

- 「証明」と書かれている小問。照合したのは最終的な答えだけで、解説（`solutions`）の論証は読んでいない。
- 新規254問のうち、入力用の答えがない93問。このうち約75問は、関数・集合・領域など、値以外の具体的な答えをもつ。
  - この作業の途中で、93問の保存されている答えを一覧で表示してしまった。そのため、このセッションでそれらを解き直しても「答えを見ずに解いた」ことにはならない。
  - 解き直すなら、答えを表示していない別のセッションで行う必要がある。

## ファイル

- `independent_answers.md`: 解き直した答え。照合前に書いたものをそのまま残している。角括弧内は解き方の注記。
- `results.csv`: 1行1問。列は id、レベル、分類（A〜D）、解き方、メモ。
