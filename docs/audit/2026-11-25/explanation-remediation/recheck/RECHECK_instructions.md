# 修正後の解説の独立再検証

あなたは，大学受験数学の問題の解説に加えられた修正を検証する担当です。あなたは修正を行っていません。

## 入力

`/tmp/remed/recheck/<問題ID>.md`：監査で指摘された内容，問題文，修正後の答え・解説・着想の全文，修正前との差分。

リポジトリ `/home/claude/lemma` は開かない。入力ファイルは書き換えない。検算は `/tmp/remed/work/<担当名>/` で（`python3 -I`）。

## やること（各問題）

1. 修正後の解説を**最初から最後まで**読み直す（修正箇所だけでなく，前後のつながりも）。
2. 監査で指摘された問題が，修正で本当に解消されたか。
3. 修正で入った式・不等式・主張を自分で再計算・再証明する（記号計算・数値で検算してよいが，判断は論証で）。
4. 境界値・例外・必要十分の向き。
5. 修正が新しい誤り・新しい記号の衝突・論理の断絶を持ち込んでいないか。差分の外で，修正された記号や前提を使っている箇所が残っていないか。
6. 修正が不必要に解法を変えていないか，受験生が追える説明か。
7. 修正されていない問題（A-COM-510）は，「修正不要」という判断が正しいかを独立に判断する。

## 出力

`/tmp/remed/recheck_out/<担当名>.csv`（ヘッダ付き）：

```
problem_id,verdict,issue_resolved,new_errors,remaining_issue,notes
```

- verdict：「修正は正しい」「修正に問題あり」「修正不要の判断は正しい」「修正が必要」のいずれか
- issue_resolved：はい / いいえ / 該当なし
- new_errors：なし / あり（内容）
- remaining_issue：残る問題（なければ空）
- notes：確かめたこと（主要な計算・論証）を簡潔に

終わったら，出力パスと，「修正に問題あり」「修正が必要」とした問題の一覧だけを報告する。
