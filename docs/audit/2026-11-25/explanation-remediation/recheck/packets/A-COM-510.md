## 問題文

$m,n$ を2以上の整数とし，$m$ 行 $n$ 列の表の第 $i$ 行第 $j$ 列に数 $a_{ij}$ を書き込む．ただし各 $a_{ij}$ は $1$ または $-1$ である．$1\leqq k<l\leqq m$，$1\leqq p<q\leqq n$ かつ $l-k=q-p$ をみたすすべての $k,l,p,q$ に対して
\[
a_{kp}+a_{kq}+a_{lp}+a_{lq}=0
\]
が成り立つとき（すなわち，表の中の各辺が縦横に平行な正方形についても，4隅の数の和が $0$ であるとき），この表は性質 Q をもつという．
\begin{enumerate}
  \item $m=n=4$ のとき，性質 Q をもつ表は何通りあるか．
  \item $m=4$，$n\geqq3$ のとき，性質 Q をもつ表に含まれる $1$ の個数は，表によらず $2n$ であることを示せ．
  \item $m\geqq5$ かつ $n\geqq5$ のとき，性質 Q をもつ表は存在しないことを示せ．
\end{enumerate}

## 解答・解説（修正後，全文） main

\textbf{準備．} $\pm1$ の4数 $x,y,z,w$ の和が $0$ であるのは，ちょうど2つが $1$ のときである．よって
\begin{itemize}
  \item[(ア)] $x=y$ ならば $z=w=-x$，
  \item[(イ)] $x\neq y$ ならば $z\neq w$
\end{itemize}
が成り立つ（(イ) は $x+y=0$ から $z+w=0$ となることによる）．

性質 Q をもつ表を考える（$m,n\geqq2$）．1辺1の正方形（$l=k+1$，$q=p+1$）の条件に (ア)(イ) を適用する．$1\leqq j\leqq n-1$ に対し $\beta_{i,j}=a_{i,j}a_{i,j+1}$ とおくと，(ア)(イ) から $\beta_{i+1,j}=\beta_{i,j}$ である（(ア) の場合 $a_{i+1,j}a_{i+1,j+1}=(-x)^2=1$，(イ) の場合 $-1$）．よって $\beta_{i,j}$ は $i$ によらない．これを $\beta_j$ と書く．同様に（行と列の役割を入れかえて）$\gamma_i=a_{i,j}a_{i+1,j}$（$1\leqq i\leqq m-1$）は $j$ によらない．

ある $j$ で $\beta_j=1$ なら，(ア) よりすべての $i$ で $a_{i+1,j}=-a_{i,j}$，すなわちすべての $\gamma_i=-1$．したがって，次のどちらかが成り立つ．
\begin{itemize}
  \item[(I)] すべての $\gamma_i=-1$：$a_{ij}=(-1)^{i-1}v_j$（$v_j=a_{1j}$）．
  \item[(II)] すべての $\beta_j=-1$：$a_{ij}=(-1)^{j-1}w_i$（$w_i=a_{i1}$）．
\end{itemize}
（(I) でないならある $\gamma_i=1$ であり，上と同様にして，すべての $\beta_j=-1$ となる．）

(I) の形の表で，左上が $(k,p)$，1辺 $s$ の正方形の4隅の和は
\[
(-1)^{k-1}\{1+(-1)^s\}(v_p+v_{p+s})
\]
である．$s$ が奇数なら $0$．$s$ が偶数なら，条件は $v_{p+s}=-v_p$ である．ここで $s$ はこのような正方形がとれる値，すなわち $s\leqq m-1$ かつ $p+s\leqq n$ の範囲を動く．したがって
\begin{center}
(I) の形の表が性質 Q をもつ $\iff$ 偶数 $s\leqq m-1$ と $1\leqq p\leqq n-s$ について常に $v_{p+s}=-v_p$．
\end{center}
(II) についても，行と列を入れかえた同じ結論が成り立つ．

また，$m,n\geqq3$ のとき (I) と (II) を同時にみたす表は $a_{ij}=(-1)^{i+j}a_{11}$ であるが，1辺2の正方形の4隅はすべて $a_{11}$ に等しく，和は $\pm4\neq0$．よって (I)，(II) の両方をみたす，性質 Q をもつ表はない．

(1) $m=n=4$．(I) の条件は $s=2$ のみで，$v_3=-v_1$，$v_4=-v_2$．$v_1,v_2$ は自由に選べて $4$ 通り．(II) も同様に $4$ 通り．重なりはないので $\boldsymbol{8}$ 通り．

(2) $m=4$，$n\geqq3$．\\
(I) の場合，条件は「$v_{p+2}=-v_p$（$1\leqq p\leqq n-2$）」で，第2行は第1行の符号をすべて反転したもの，第3行は第1行，第4行は第2行に等しい．第1行と第2行の $1$ の個数の和はちょうど $n$ なので，表全体の $1$ の個数は $2n$．\\
(II) の場合，$s=2$ の正方形がとれる（$m-1=3\geqq2$，$n\geqq3$）ので $w_3=-w_1$，$w_4=-w_2$．各列は $(-1)^{j-1}(w_1,w_2,-w_1,-w_2)$ で，どの列にも $1$ がちょうど2個ある．よって $1$ の個数は $2n$．\\
いずれの場合も $1$ の個数は $2n$ である．\hfill$\square$

(3) $m,n\geqq5$ とする．(I) の場合，$s=2$（$p=1,3$）から $v_3=-v_1$，$v_5=-v_3=v_1$．一方 $s=4$（$4\leqq m-1$，$p=1$，$1+4\leqq n$）から $v_5=-v_1$．よって $v_1=-v_1$ となり $v_1=\pm1$ に矛盾．(II) の場合も行と列を入れかえて同様に矛盾する．したがって性質 Q をもつ表は存在しない．\hfill$\square$

## 着想（修正後）

$\pm1$ の4数の和が $0$ なら，ちょうど2つが $1$．$2\times2$ のブロックでは「上の2数が等しければ下の2数はその符号を反転したもの」「上の2数が異なれば下の2数も異なる」．これで横に隣り合う2数の積 $a_{i,j}a_{i,j+1}$ は行によらず，縦の積も列によらない．どこかで横の積が $1$ なら縦の積はすべて $-1$ となり，表は「1行目を符号を交互に変えて並べたもの」か「1列目を符号を交互に変えて並べたもの」に限られる．あとは1辺が偶数 $s$ の正方形の条件が「$s$ 離れた2数は異符号」となり，$s=2$ と $s=4$ が同時に入ると矛盾する．原題の「縦横の差が $\pm2$ の長方形」を「正方形」に変え，表の個数・1の個数・非存在を問う．
