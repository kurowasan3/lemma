## 2. 新しいカード

| 項目 | 値 |
|---|---|
| ID | `circle-tangent`（77枚目。「方べきの定理・円の性質」の次） |
| 名前 | 円の接線と半径（垂直・接線の長さ） |
| 種類・分類 | 定理・公式（theorem）・図形・ベクトル（geo） |
| tags・weak | どちらも空。タグでは自動に結びつかず、管理表の「解法」列でだけ結びつく |
| rel・alt | power-point・law-sin-cos・projection／coordinate |
| reviewed | false（人の確認はまだ） |

- summary・essence・when・cue・caution は card_definition.md の案のまま。
- caution には、ほかのカードの担当を書いた。
  - 接線の方程式・接点を文字で置く方法 →「接線（接点を文字で置く）」
  - 接する条件を中心と直線の距離に直す方法 →「正射影・垂線の足・距離」
  - 方べき・相似 →「方べきの定理・円の性質」
- 「方べきの定理・円の性質」は、文言だけを調整した。結びつく問題は変わらない。
  - 使う場面：「円と2直線・接線の長さ・…」→「円と2直線（割線・接線）が交わってできる線分の長さの積・…」
  - 着眼点：「接線の長さそのものを半径との直角三角形で出すなら『円の接線と半径』」を書き足した。

- 「接線の長さ」タグは、内サイクロイドの問題（III-INT-216）にも付いている。タグの意味が2つある状態は、このままにしている。
