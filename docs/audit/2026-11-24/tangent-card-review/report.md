## 4. 新カードを作るべきか：**作るべき**

### 検証（Phase 3 の6項目）

1. **共通の数学的構造がある**。B の13問はすべて (a) か (b) が決め手。(b) は (a) から出る（接点への2本の半径と、中心と円外の点を結ぶ線分でできる2つの直角三角形が合同）。1枚のカードにまとめられる。
2. **既存カードとの重なりは区別できる**。
   - 「方べきの定理・円の性質」：「使う場面」に接線の長さがあるが、方法は相似・方べき（$PT^2=PA\cdot PB$）。B の13問のうち、相似や方べきで解くものは0。最も近い II-GEO-259（$PT^2=OP^2-r^2$）も、解説は直角三角形から出している。
   - 「正射影・垂線の足・距離」：接する条件を「中心と直線の距離＝半径」とする使い方はこちら。新カードの定義から外した（card_definition.md）。
   - 「正弦定理・余弦定理」：三角形の辺と角の計算。I-TRI-012 などは補助に入れる。
   - 「接線（接点を文字で置く）」：曲線の接線の方程式を立てる方法で、B の13問はどれも接線の方程式を立てない。
3. **接線が出てくるだけの問題は除いた**。§3 の4問（C-VEC-247・A-GEO-092・I-TRI-100・II-GEO-028）は B に入れていない。円が接するだけで、中心間距離や点と直線の距離で解く問題（II-GEO-079・B-SEQ-036・A-GEO-048）も B に入れていない。
4. **ほかの問題へ転用できる**。B の13問は6分野にまたがる：数A 図形の性質 7、数II 図形と方程式 2、数I 図形と計量 1、数II 三角関数 1、数C 複素数平面 1、融合 1。同じ直角三角形の見方が、偏角の範囲（C-CUR-140）、等比数列になる円の列（X-MIX-034）、楕円上の点からの接線（II-GEO-252）に出てくる。
5. **粒度は適切**。教科書の1項目（数A「円の接線」：接線と半径の垂直・接線の長さ）に当たり、「方べきの定理」と同じ大きさ。難易度は0〜3（0：1問・1：3問・3：9問）で、基礎・標準の反復に向く。
6. **既存カードの修正で対応する案は採らない**。「方べきの定理・円の性質」を広げて (a)(b) を入れることもできる。しかしそのカードの本質（等しい角と比例する長さ＝相似）とは別の方法なので、1枚に2つの方法が入る。習熟の判定でも区別できなくなる。新しく分ける方がよい。

## 9. 解法体系全体への影響（impact_analysis.csv）

| 項目 | 新カードを作る | 作らない |
|---|---|---|
| 主を新しく設定（今は主なし） | 17（B 7・A 10） | 14（A 10・B 4） |
| 主を別のカードへ変更 | 6（すべて「接線」→新カード） | 2（「接線」→ド・モアブル／相加相乗平均） |
| 主を外す（「接線」→主な解法なし） | 0 | 4（A-GEO-011・023・075・084） |
| 明示の「主な解法なし」（主は変わらない） | 1 | 1 |
| 変更なし | 9（D） | 12（D 9・主なしのまま3） |
| 合計 | 33 | 33 |

- **作る場合**
  - 新カードの主は13問。そのうち既存カードから移るのは6問（すべて「接線」から）、7問は今は主なし。
  - 「接線」カードの主な解法は 197 → 191。
  - 補助として残す：「接線」から移る6問は、v0.28.1・v0.28.2 と同じく、今の結びつきを補助に残す。
  - 補助に新カードを付ける：A の3問（A-GEO-017・A-INT-143・I-TRI-081）。weak のタグ2つで、補助として自動で結びつく問題は25問。
- **作らない場合**
  - 数A の初等幾何の7問（共通接線の長さ・接線の長さ）は、合う主が無い。4問は「接線」から外して主な解法なし、3問は主なしのまま。
  - 残りの6問は、近い既存カード（最大・最小、方べき、ド・モアブル、正弦定理、漸化式、相加相乗平均）に入る。ただし、決め手の方法（接線と半径の直角三角形）はどのカードにも表れない。
- **カード全体への影響**：作るとカードは 76 → 77枚。既存カードの分割・統合は無い。「方べきの定理・円の性質」の「使う場面」の「接線の長さ」は、新カードと重なる。新カードを作るときに、方べきのカードの側を「接線なら $PT^2=PA\cdot PB$」に絞る文言の調整が必要。
- **学習上の効果**：今は数A の共通接線の基本問題（難易度0・1）が「接線（接点を文字で置く）」の主になっていて、微分の接線の習熟に混ざっている。分けると、微分の接線と初等幾何の接線の習熟が別々に判定され、推薦も正しい練習先を示せる。
