## 2. 空欄・明示の「なし」・自動の仕様

| 主な解法 | 補助の解法 | 意味 |
|---|---|---|
| 空欄 | 空欄 | 未指定 → タグから自動（v0.28 と同じ規則。weak だけに当たれば「自動の主なし」） |
| 名前 | 名前の並び | 明示：主・補助（タグは使わない） |
| 名前 | 補助の解法なし | 明示：主・補助なし |
| 主な解法なし | 名前の並び | 明示：主なし・補助あり |
| 主な解法なし | 補助の解法なし | 明示：主なし・補助なし |
| 片方だけ空欄 | | 誤り（取り込みを止める） |

- 空欄は、いつでも「未指定」だけを意味する。明示の「なし」は予約語で書く。
- 並びや位置で主・補助が決まることはない。補助の列の並びは、補助どうしの順だけ。
- 誤り：片方だけ、主に2つ、無い名前、補助の重複（別名・旧IDも同じカード）、主と同じ補助、予約語を名前として使う、旧 `techniques`。誤りの指定から主を推測しない。
- **旧「解法」列**は、v0.29.0 の移行期間だけ読む。
  - 新しい2列と一緒にあれば誤り。
  - 「主な解法なし」の行は誤り（補助がタグ由来で、1列からは決められない）。
  - 旧形式の管理表は `tools/xlsx_technique_columns.py` で変換する。読み込みは v0.29.1 で消す。

## 8. Supabase・学習記録への影響

- **Supabase**：同期する内容（学習記録・復習状態・ブックマークなど。どれも問題IDで持つ）は変わらない。サーバーの関数や表は変えていない。本番には書き込んでいない。同期の単体テストとサーバー側の制限のテストが通った。
- **学習記録・想起・ブックマーク**：形式も中身も変えていない。移行は不要。
- **習熟・推薦**：data の結びつきが変わったのは3問だけ。その3問を解いた記録は、次のように数え方が変わる。
  - 「接線」の補助の問題として数えていた記録（得意度の重み0.5）は、circle-tangent の補助の問題として数える。
  - 主が無いので、想起の質問と転用の判定には今までどおり使わない。
  - 推薦のストレステストと習熟の単体テストは通った。
