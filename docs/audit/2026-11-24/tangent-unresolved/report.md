# v0.28.2 候補：「接線」カードの未対応20問の再監査と、主な解法の分類の検討

監査と設計だけで、アプリのデータ・コード・問題は変えていない。件数はすべて review.csv（20行）と excel_status.csv（11行）から数えた。

## 1. 対象の確認

- link_review.csv（v0.28.1）で、判定「誤り」かつ対応「未対応（ほかに明確な主な解法がなく、主な解法なしを指定する仕組みが無い）」の行：**20**（重複なし）。
- 現在のデータとの照合：20問とも公開中で、主な解法は「接線（接点を文字で置く）」、管理表の「解法」の指定は無い。
- 「接線」カードの主な解法は今 207問 ＝ 正しい・保留 187 ＋ この20。漏れも余分もない。

## 3. 判定ごとの根拠

### A：既存カードへ（8問）

| 問題 | 移す先 | 根拠 |
|---|---|---|
| C-CUR-193 | 2次曲線（焦点・媒介変数） | 楕円を媒介変数で表して合成。カードの「曲線上の点の最大最小」に当たる |
| C-CUR-356 | 通過領域 | 解説の大半が線分 OQ の通過範囲 |
| C-VEC-181 | 逆像法（実数条件） | 「残りの成分が存在する ⇔ $s^2\leqq1$」で範囲を出す |
| C-VEC-441 | 逆像法（実数条件） | 中点 M を固定して、P が存在する条件を求める |
| III-DIF-099 | 解の配置 | $s=\sqrt{x+1}$ と置き換えた2次不等式の解の位置の条件 |
| III-DIF-122 | 定数分離 | $q=e^x-px$ と分離して最小値と比べる |
| III-INT-086 | 定数分離 | $b\leqq\min(e^x-ax)$ と分離（不等式の定数分離） |
| III-DIF-196 | 最大・最小の求め方 | 図形の量（体積・表面積）の最大。接線は長さを出す1行だけ |

5問（C-CUR-193・C-CUR-356・C-VEC-181・C-VEC-441・III-DIF-196）は、移す先のカードにすでに補助として結びついている。移すには、管理表の「解法」列で先頭を指定すればよく、新しい仕組みはいらない。注意点が2つある：
- 「最大・最小の求め方」はタグがすべて weak で、自動では主にならない。
- 定数分離のカードの「使う場面」は方程式の解の個数が中心なので、不等式に使う2問はカードの例と少しずれる。

### B：新しいカード「円の接線と半径」（4問）

4問とも数A「図形の性質」（難易度 0〜3）で、次の流れで解いている：接線⊥半径 → 長方形と直角三角形を作る → 三平方で共通接線の長さ（外接する2円なら $2\sqrt{Rr}$）。円外の点から引いた2接線の長さが等しいことも使う。接線の方程式は使わない。

既存の「方べきの定理・円の性質」は「使う場面」に接線の長さを含む。ただし方法は相似と方べき（$PT^2=PA\cdot PB$）で、三平方で長さを出す方法とは別のもの。ここに入れるのは無理な押し込みになると判断した。

### C：主な解法なし（2問）

- **II-GEO-212**：両軸に接する円を、中心 $(a,a)$ と置いて円の方程式を解くだけ。方法として独立したカードに当たるものが無く、作るほどでもない。
- **III-DIF-131**：中心は式の変形と微分の計算。接線は求めた微分係数を1回使うだけで、接点を文字で置く方法ではない。

### D：判断保留（6問）

保留の理由は2種類ある。

**新しいカードの有無で主が変わる（3問）**
- **C-CUR-140**：偏角の範囲を、接線と半径の直角三角形で出している。
- **II-TRI-062**：接線の長さが等しいことで辺を表し、相加相乗平均で最大を出す。
- **III-DIF-272**：辺を接線の長さに分け、最小値を求める。

B のカードを作るならそれが主、作らないなら「ド・モアブルの定理」「相加平均・相乗平均」「最大・最小の求め方」がそれぞれの候補。

**小問ごとに方法が分かれ、主を1つに決める基準が無い（3問）**
- **C-CUR-407**：弦の長さ（解と係数）・場合分けつきの最大・伸縮による面積。
- **II-GEO-228**：2倍角・円の方程式と垂直条件・因数分解。
- **II-CAL-289**：解き方は平方完成と場合分け。ただし答えの直線は共通接線そのもの。主な解法を「答えの意味」と「解く手順」のどちらで決めるかで変わる。

## 4. 新規カードの候補

**名前の案：「円の接線と半径（垂直・接線の長さ）」**
- 使う場面：円・球の接線の長さ、共通接線の長さ、円に外接する多角形の辺。
- 発想の起点：接点へ半径を引いて直角を作る。

| 観点 | 評価 |
|---|---|
| 対象問題数 | 今回の B が4問。D のうち3問は、作れば主になる。v0.28.1 で「接線の長さ」を weak にして主な解法なしになった7問（A-GEO-009・017・018・083、I-TRI-081、II-GEO-254・259）も、判定の根拠が同じ初等幾何。タグから見た候補は、主な解法なしの問題に最大23問（未確認）。 |
| 汎用性 | 数A の図形、数I の三角比（内接円）、数II の図形と方程式、数C の空間（球の接線：C-VEC-349・436 など）、数III の立体（III-DIF-196）にまたがる。 |
| 独立した学習価値 | 高い。接線⊥半径から直角三角形を作るのは、初等幾何で最初に身につける基本の方法。「接点を文字で置く」（微分・座標の方法）とは、考え方がまったく違う。 |
| 既存カードとの重なり | 「方べきの定理・円の性質」と、接線の長さの場面だけ重なる。方法（相似・方べき と 三平方）で分けられる。 |
| 独立させた効果 | 初等幾何の接線の問題が「接点を文字で置く」の練習に混ざらなくなり、習熟の判定が正しくなる。主な解法なしの問題に、練習先ができる。 |
| 基礎・標準の反復 | 向いている。候補の多くが難易度 0〜3。 |

ほかの候補（「微分の計算」「円の方程式の決定」「ルジャンドル変換・支える直線」）は作らない。前の2つは方法というより計算で、最後の1つは1問だけ。

## 5. 「主な解法なし」の扱い方の比較

前提として、**主な解法の無い問題はすでに 1,230問ある**（アプリの問題 5,216問のうち。data/index.json と data/techniques.json から数えた。タグがどのカードにも当たらない問題）。ビルド・解答画面・習熟・推薦は、主な解法が無い問題をもう扱えている。足りないのは、管理表から「この問題は主な解法なし」と**指定する手段**だけ。

| 方式 | 内容 | 互換性 | 管理表 | ビルド | UI | 学習記録 | 評価 |
|---|---|---|---|---|---|---|---|
| 1. 明示指定 | 「解法」列の先頭に「主な解法なし」と書く（例：`主な解法なし、接線（接点を文字で置く）`） | 今の指定に影響しない | 1語足すだけ（列そのものは要追加。§6） | 先頭がこの語なら主を空にし、残りを補助にする（数行） | 変更なし（主なしの表示はもうある） | 記録は問題 ID で持つので変わらない。カードの主な解法の数と習熟の集計が変わるだけ | **採用** |
| 2. null／未指定 | 「解法」列の空欄を主なしと読む | 空欄は今「タグから自動」の意味。全問の自動推定が消える | Excel では空欄と「空のリスト」を区別できない | — | — | — | 不可 |
| 3. 補助・タグだけ残す | カードのタグを weak にする、または問題からタグを消す | weak は全問に効き、正しい・保留の187問も変わる（v0.28.1 で確認）。タグを消すと検索と分類の情報が減る | タグ列の書き換えが必要 | 変更なし | 変更なし | 変わらない | 不可（根拠のないタグの変更になる） |
| 4. 新規カード | 方法がはっきりある問題に新しいカードを作る | 新しい ID の追加だけ | 新カードの名前を「解法」列かタグに書く | 変更なし | 解法ページが1枚増える | 変わらない | **B だけに採用**（C と D には使えない） |

## 6. 管理表との整合（v0.28.1 の11問）

v0.28.1 では「管理表の『解法』列で指定」と書いたが、確かめると**今の管理表には「解法」列そのものが無い**。元のファイルにも、復旧版（Lemma_問題管理表_restored.xlsx）にも無い。列は ID・作成日 …… タグ・メモの19列。v0.28.1 の報告にはこの訂正を書き足した。

| 項目 | 結果（excel_status.csv） |
|---|---|
| technique_changes.csv | 11件 |
| アプリ側（content/problems の `techniques`） | 11件ともあり（公開中で指定があるのはこの11問だけ） |
| 指定の先頭が今の主な解法 | 11 / 11 |
| 指定した解法がすべて結びついている（主と補助が合っている） | 11 / 11 |
| 元の管理表の行 | 10（II-CAL-303 は行が無い） |
| 復旧版の行 | 11 |
| 管理表の「解法」列 | 無い → **11件とも未反映** |

- **危険**：取り込み（tools/xlsx_to_content.py）は管理表から content/problems を書き直す。「解法」列が無いまま取り込むと、11問の指定が消えて主な解法が「接線」に戻る。v0.28.0 のタグの追加（tag_changes.csv）も、管理表に反映されていなければ同じように消える。
- **安全な反映の方法**：
  1. 復旧版のコピーを作り、「メモ」の前に「解法」列を足して11問に書き込む。元のファイルと復旧版は上書きしない。
  2. 書いたあと、コピーの「解法」列と content の `techniques` を全問照合する。
  3. 取り込みは、管理表の取り込みの方針を決めるまでしない。
- 取り込みの処理は見出しの名前で列を探すので、列の位置はどこでもよい。

## 8. 最小限の改修方針

1. 「解法」列の先頭に「主な解法なし」を書けるようにする（方式1）。
2. A の8問を「解法」列で移し、C の2問を「主な解法なし」と指定する（10問）。
3. B のカードと D の6問は、そのあとに別の版で扱う。カードの文章（概要・本質・使う場面・発想の起点）を人が書き、候補（最大23問）を1問ずつ確かめてから作る。

UI・学習記録・推薦の仕組みは変えない。

## 9. 次の実装で変更するファイル（方式1＋A・C の10問）

- tools/build_app_data.py：先頭が「主な解法なし」なら主を空にし、残りを補助にする。
- tools/audit_data.py・tools/audit_techniques.py：「解法」の名前の検査で、「主な解法なし」を正しい値として認める。「主な解法なし」が先頭以外にあれば誤りにする。
- tests/technique_links_test.py：「主な解法なし」の指定なら、どのカードの主でもないことを確かめる。今回の20問の判定（A・C）も記録に加える。

- アプリの画面（js/）は変えない。

## 10. 実装のリスク

- 「主な解法なし」という語が、将来のカード名と重なるおそれ。→ 検査で、同じ名前のカードを作れないようにする。
- 管理表に「解法」列が無いまま取り込むと、指定がすべて消える（11問＋次の10問）。→ §6 の手順で先に列を足す。
- 習熟・推薦の集計が少し変わる（主な解法の数が動くカードが7枚）。学習記録は失われない。
- 定数分離に移す2問は不等式の問題で、カードの例（方程式の解の個数）と少しずれる。カードの「使う場面」に不等式を足すかは、別に判断する。

## 11. 次の版でするべきこと（1つ）

**管理表の「解法」列に「主な解法なし」と書けるようにし、A の8問と C の2問を直す。**

理由：主な解法なしの状態は、もう1,230問で動いている。足すのは「指定する手段」だけで、変更が最も小さい。そのうえで、20問のうち10問（半分）の誤りがすぐに直る。B の新しいカードは効果が大きいが、カードの文章を書き、候補23問を確かめる必要があり、その次に回すのがよい。前提として、§6 の「解法」列を管理表のコピーに足す作業を同じ版で行う。

## 12. 結論：分類の体系に必要なもの

**両方必要。ただし役割が違い、順番がある。**

- **主な解法なしの許容**は、体系の土台として必要。20問のうち C の2問は、どんなカードを作っても主な解法が無い（計算や基本の方程式だけの問題）。自動の推定でもすでに1,230問が主なしになっている。主な解法を無理に割り当てないことは、v0.28.0 から一貫している（誤った解法を示すより、示さない方がよい）。
- **新規カードの追加**は、既存のカードで説明できない、はっきりした方法があるときだけ必要。今回それに当たるのは「円の接線と半径」の1枚だけ。ほかの手法（定数分離・逆像法・解の配置など）は、既存のカードに入る。
- **D の6問**は、新規カードの判断（3問）と、「小問ごとに方法が分かれる問題の主をどう決めるか」の基準（3問）が決まれば判定できる。後者の基準は、v0.28.1 の保留80問にも共通する課題になっている。
