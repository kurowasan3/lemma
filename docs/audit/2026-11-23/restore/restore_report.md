## 4. `import_xlsx.py --check` の結果（チェックだけ。取り込みはしていない）

- **消える問題：0**。ID の変更で削除や追加の扱いになる問題は無い。
- **増える問題：255** ＝ 新しい 254問 ＋ I-EXP-057（アプリでは非表示だが、管理表のタグに「非表示」が無いので公開になる。元の管理表から）。
- **中身が変わる問題：3,726**。すべて原因が分かっている：

| 原因 | 件数 | 説明 |
|---|---|---|
| 管理表に「入力用の答え」の列が無い | 3,701 | アプリの 3,701問の入力用の答え（と、そこから作る選択式の選択肢）が消える。元の管理表からの問題で、復旧とは関係ない |
| v0.27.0 でアプリ側だけ直した問題 | 24 | 管理表は修正前（fixes.csv）。一部は上の 3,701 にも含まれる |
| 同じ ID で言い回しが違う | 6 | どちらの文を残すかは人が決める |

**このままでは取り込めない。** 取り込む前に、少なくとも次が要る：

1. 「入力用の答え」の列を足し、content/ の値を入れる（入れないと自動採点が消える）。
2. v0.27.0 の修正 24問を反映する（v0.27.1 と同じ手順。修正前と一致するセルだけ）。
3. I-EXP-057 のタグに「非表示」を足すか決める。
4. 言い回しの違う 6問で、どちらの文を残すか決める。

この4つの後なら、`--check` の差は「新しい 254問が増える」だけになる見込み（そのとき改めて確かめる）。
