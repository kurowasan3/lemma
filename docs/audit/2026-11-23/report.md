# 品質監査レポート（v0.27.0・2026-11-23、v0.27.1 で件数を訂正）

公開している問題と解法カードを、数学教材として実際に使えるかという観点で監査した。点数は付けない。件数や合格率で良し悪しを判断しない。

**この監査は AI（Claude）が行った。人による確認ではない。** 人の確認の記録（`content/quality/human.json`）は作っていない（ファイル自体が無い）。人の確認は 0問のまま。

## 1. 対象と方法

| 対象 | 数 |
|---|---|
| 公開問題 | 5,216問（基礎 280・入試基礎 280・標準 238・入試標準 1,434・入試発展 2,383・数学探究 601） |
| 解法カード | 76枚 |

使った道具（新しい仕組みは作っていない）：

- `tools/verify_math.py`：答えの値を計算し直して照合し、形の不整合（小問と答えの対応など）の候補を出す。今回、誤検出の原因を直した（verify_math 2）。
- `tools/audit_problems.py`：類似・役割の重なり・優先度。今回「答えが同じで問題文の数字も近い」組の検出を加えた。
- `tools/audit_techniques.py`：解法カードの記述と問題への結びつけ。

AI レビューの範囲：

- 基礎・入試基礎・標準（798問）から、分野×難易度ごとに頻出度の高い2問ずつ、114問を抜き取り、問題文・答え・解説を読んで検算した。
- 道具が優先1・2に挙げた問題と、形の不整合の候補（80問）をすべて読んだ。
- ai_review.csv の 142問は、抜き取り 114問（うち5問は構造の候補か優先1にも該当）と、抜き取り以外の 28問（構造の候補 21問・優先1 7問）。構造の候補 80問のうち道具の誤検出だったものと、修正前の優先2 の問題は ai_review.csv に入れていない。
- 解法カード 76枚の記述をすべて読み、自動で主になった解法 30件を抜き取って問題と照らした。

## 3. 修正したもの

| 対象 | 内容 | 理由 |
|---|---|---|
| I-EXP-031 | 解説の商を $(x^2-6x+7)(x^2+x+1)+9x-6$ に訂正 | 解説の計算が誤っていた |
| A-INT-233 | (2) を特殊解 $x=4,\ y=31$ から直接求める形に（一般解 $x=4+8k,\ y=31-13k$、$k=0,1,2$）。元の経路は注として残した | ×300 する経路が遠回りで、再現しにくい |
| 11問 | 1行に並んだ `\qquad (2)` を `\item` に分けた | 小問ごとに答えと採点が対応しない |
| 12問 | 抜けていた小問の答えを補い、答えを小問ごとに分けた（図示は「図示（解答参照）」） | 答えの抜け |
| 確率漸化式カード | タグから「点の移動」を外した | このタグの10問はすべて図形の1次の移動で、確率の問題ではなかった。7問は合う解法が主になった |

列ごとの修正前・修正後は **fixes.csv**。**この修正は Excel 管理表にも反映する必要がある**（次に取り込むと上書きされるため）。

**v0.27.1 での管理表への反映**（受け取った管理表 4,913行・2026-11-23 20:49 受領のコピーに対して）：24問は「修正前」と一致したので「修正後」に置き換えた。A-INT-233 は競合（管理表の A-INT-233 はアプリの A-INT-263 にあたる別の問題で、アプリの A-INT-233 は管理表に無い）で書き換えていない。記録は excel_apply_log.csv。

ただし、**この管理表はアプリの content/ と ID の対応が合っていない**（excel_divergence.csv）。同じ ID が別の問題を指すものが 1,358問、アプリにだけある問題が 368問、管理表にだけある問題が 64問ある。取り込むと、学習記録が別の問題に結びつき、368問が消えるので、**取り込んではいけない**（`--check` で確認。content/・data/ は変えていない）。どちらを正本として ID をそろえるかは人が決める。

## 4. 解法体系

- 76枚とも「使う場面・着眼点・注意」が具体的で、数学的な誤りは見つからなかった。
- 主な解法の結びつけは、タグの順で推定しているため、タグの語が同じだけの誤りが出る。カードのタグを外すと正しく結びついている問題まで外れるので（単調性は数III の微分の問題では正しい）、問題ごとに管理表の「解法」列で指定する。
- 「最大・最小の求め方」は主になる問題が0問、「接線」は231問。
- 入試基礎以上で主な解法の無い問題が 1,047問ある。

## 6. 今後の改善計画

1. 上の A〜D を人が行う。D の結果だけを `--reviewed --record` で人の確認として記録する。
2. 重複の判断が済んだら、残さない問題を管理表で非公開にする（ID は欠番にして再利用しない）。
3. 主な解法の無い 1,047問のうち、入試標準の頻出問題から管理表の「解法」列を埋める。
4. 入試発展・数学探究は今回ほとんど読めていない。分野ごとに抜き取って同じ方法で監査する。
5. 自動検証の対象外が多い（5,127問）。対象を広げるより、人の確認を優先する。
