# Lemma 受験数学

答えを見せるのではなく、自力で解ける頭をつくる大学受験数学アプリ（試作版 v0.22）。

**理念**：お金がなく参考書すら買えない受験生でも、登録なしで十分に使えること。運営は、余裕のある人の有料会員（広告非表示など）で成り立たせる。
基礎・標準の少ない問題は周回し、入試発展以上の問題は量をこなす。演習・復習・ヒント・解説は誰でも無料。
iPhone・iPad のブラウザで動き、ホーム画面に追加するとアプリとして使えます（PWA）。

## できること

- **今日の学習**：ホームの一番上に、今日解いた数／目標、中断した演習の「前回の続き」、復習待ちを先に新しい問題で埋める「今日の演習を始める」（データが十分な苦手分野から最大2問）。解答後は「類題を1問追加」で同じ分野・近い難易度の問題を次に差し込める。自信なしで正解した問題は早めに復習に出す
- **全分野ランダム**：数I〜数Cの全範囲から、単元を混ぜて出題（交互練習）
- **分野ごとに演習**：科目または単元をタップして出題。難易度と問題数を指定でき、未着手・久しぶりの問題を優先
- **復習**：解法ごとに忘れ方を推定し、忘れかけたものを出題
- **段階ヒント**：答えは出さず、方針 → 道具 → 最初の一手の3段階
- **自信度**：答える前に「自信なし / たぶん / 確実」を選び、過信とのズレを記録
- **答えを入力して自動採点**：証明・図示以外は答えを入力。`2x/(1+x^2)` と `2x/(x^2+1)` のように書き方が違っても同じなら正解（乱数代入で判定）。範囲・順不同の組・比・積分定数つきの式にも対応し、場合分けが要る答えは「場合分けする」ボタンで条件ごとに入力
- **解答の形式を選べる**：設定 →「解答の形式」で **記述式**（答えを入力して自動採点）・**選択式**（4択から選ぶ。やり直しなし）・**自己採点**（紙に解いて答え合わせ）を切り替え。選択肢のない欄は入力、証明・図示は自己採点になる。記録には形式も残る（選択式の正解は、復習の間隔を「確実」でも少し短めにする）
- **判定がおかしい？**：正しいはずなのに×のときは、その欄を正解として記録（CSVに残る）
- **計算トレーニング**：微分・積分・極限・展開と因数分解・三角関数・指数対数を、その場で作る問題で反復。自己ベストを記録
- **ルート（鳥）**：休憩や体調を気づかう声かけ、勉強のアドバイス、名言（アプリを開いているあいだだけ）
- **アカウントと同期**：メールに届くコードでログインすると、学習記録を複数の端末で使え、サーバーにも保存される（Supabase）。ログインしなければ今まで通り端末の中だけ
- **ライト／ダーク**：設定で 自動・ライト・ダーク を選択。採点の効果音（オン・オフ可）
- **予想してから描く**：グラフの概形を指で描き、本物と重ねて見比べる
- **グラフ電卓（2D）**：陽関数・陰関数・不等式の領域（連立も可）・媒介変数・極座標・点・スライダー
- **問題を解きながらグラフ**：問題画面の「グラフ」で下からグラフが開く。閉じても入力中の答え・経過時間はそのまま
- **複素数平面**：z が動く点。`|z-1|=2`（円）、`arg(z)=π/4`（半直線）、`|z-α|=|z-β|`（垂直二等分線）、`1<=|z|<=2, Re(z)>=0`（領域。カンマで「かつ」）、`z^3=1`（解を点で）、`α=1+2i`（点。以後 α として使える）、`z=e^(it) t:0..π`（曲線）。関数 Re Im conj arg abs sqrt exp log sin cos
- **ベクトル方程式の図示**（グラフの「平面」にそのまま書ける）：p が動く点の位置ベクトル。小文字 `a=(2,1)` は矢印、大文字 `A=(1,3)` は点。`p=A+t(B-A)`（直線）、`…, 0<=t<=1`（線分）、`|p-A|=2`（円）、`(p-A)·(p-B)=0`（AB が直径の円）、`p=sa+tb, s>=0, t>=0, s+t<=1`（三角形の内部）、`n·(p-A)=0`（法線ベクトル）、`a·b`（内積の値）
- **空間ベクトル**（グラフの「空間」）：p が動く点の位置ベクトル。小文字 `a=(1,2,2)` は矢印、大文字 `A=(1,0,2)` は点。`p=A+ta`（直線）、`p=A+t(B-A), 0<=t<=1`（線分）、`p=A+sa+tb`（平面）、`…, s>=0, t>=0, s+t<=1`（三角形）、`|p-A|=2`（球）、`n·(p-A)=0`（平面）、`a×b`（外積の矢印）、`a·b`・`|a×b|`（値）
- **問題の図**：問題画面の「問題の図」で、問題文の式（関数・円・領域・複素数・点・ベクトル・空間の平面や点）をグラフにして開く。文字の定数はスライダー。三角形ABC・四面体ABCD は辺も結ぶ。
  「図示せよ」「軌跡」「どのような直線か」など、図そのものが答えになる問題は答え合わせのあとで開ける。「グラフに写す」で自分のグラフへ
- **グラフ電卓（3D）**：`z=f(x,y)`、平面・球・楕円面など z について2次までの式、空間曲線、媒介変数曲面、点。ドラッグで回転
- **定着度**：科目のレーダー図と分野ごとの色分けで得意・苦手がひと目でわかる（タップでその分野を演習）。自信と結果のズレも
- **検索**：テーマ・タグ・問題文の言葉で問題を探す（表記ゆれ・言い換えはタグ辞書でまとめて検索）。結果からそのまま演習
- **問題セット**：「基礎ひとまわり」などのセットを順番に。`#set=<ID>`（セット）・`#ids=<問題ID,…>`（問題）・`#search=<言葉>`（検索）のリンクで共有できる
- **ブックマーク**：問題画面の ☆ で付け外し。ホームの「ブックマークした問題」から混ぜて出題。同期すると端末どうしで揃う
- **記録の消去**：ログイン中は「この端末とアカウントの記録を消す」か「ログアウトしてこの端末の記録だけ消す」を選べる（消した印 `resetAt` で、ほかの端末の古い記録がよみがえらない）
- **ログイン時の確認**：端末とアカウントの両方に記録があるときだけ、合わせるか・アカウントの記録だけを使うか（端末の分は書き出してから消す）を聞く。ログアウト時に端末の記録を消すこともできる（共用の端末向け）
- オフライン動作、記録の書き出し・読み込み（読み込みは形を確かめてから、今の記録と合わせるか置き換えるかを選ぶ）

収録範囲：問題管理表の 5,216問（20分野）＋ 自動判定つきの内蔵問題 61問。難易度は 0=基礎・1=標準・2=入試基礎・3=入試標準・4=入試発展・5=数学探究 の6段階（「今日」の難易度ボタンで絞り込める。基礎だけを選べば易しいセットになる）。
難易度とは別に、問題ごとに**頻出度**（高・中・低）がある。入試で繰り返し使われる考え方・手法を扱う問題ほど高い。問題画面に表示し、演習ではまだ解いていない問題のうち頻出度の高いものを優先して出す（高は低の4倍、中は2倍選ばれやすい）。

**解法カード**（`content/techniques.json`、77枚）：入試数学の解法・技法ごとに、種類（基本の技法・定理公式・定石・問題解決の方針・論証）、概要・核心・使う場面・着眼点・注意点、必須の前提・先に学ぶとよい解法・別のアプローチ・組み合わせて使う解法をまとめたカード。問題は管理表の「主な解法」「補助の解法」列（主と補助を別々に指定。両方空欄ならタグから自動）で結びつき、主な解法と補助を区別する（約84%の問題が結びつく）。解法ごとに未学習・学習中・要復習・習得を判定し、「今日の演習」は復習の時期の問題に加えて、要復習の解法・未学習の解法・解法を別の分野で使う問題を、出題の理由つきで選ぶ。解答後に任意で「解法は浮かんだか」を記録でき、解法を知らされずに違う文脈（別の分野・他の解法との組み合わせ）で解けたかを「転用」として確かめる。詳しくは `docs/techniques.md`。問題の品質確認は `docs/quality.md`（自動検証 `tools/verify_math.py` と人の確認を分けて記録する）。

## 問題管理表から問題を取り込む

問題は `Lemma問題管理表.xlsx`（問題一覧シート）で管理し、スクリプトで「正規データ `content/`」と「アプリ用データ `data/`」に変換します（形式の詳細は [docs/data-spec.md](docs/data-spec.md)）。

```sh
pip3 install openpyxl jsonschema
python3 tools/import_xlsx.py Lemma問題管理表.xlsx          # content/ と data/ を作り直す
node tests/run.mjs                                       # 検査（全部 ✓ になればOK）
```

更新するときの手順：

1. いまのリポジトリの zip と管理表を、日付を付けて保存しておく（戻すとき用）
2. 上の2行を実行。`--check` を付けると、書き出さずに「今のファイルと違うか」だけ確かめられる
3. `content`・`data`・`tests` フォルダごとリポジトリにアップロード（一部だけだと「問題データの版が揃っていません」と表示されます）
4. GitHub の「Actions」タブで ✓ になっているか確認（`.github/workflows/ci.yml`。`node tests/run.mjs --e2e` と同じ検査）

- **管理表（xlsx）はリポジトリに入れない**（参考元を含むため）。「参考元」「メモ」は content/・data/ に出しません。`python3 tools/audit_data.py --xlsx Lemma問題管理表.xlsx` で漏れがないか確かめられます
- 分野ID（`I-01` など）は `content/taxonomy.json` で固定されていて、「分野一覧」シートの並びを変えても変わりません。新しい分野を足すときは `--new-fields` を付けて取り込みます
- 問題ID は変えない・消さない。消えると `tests/golden/ids.txt` との照合で検査が失敗します。出さない問題はタグに `非表示`（`content/` には残る）
- 問題を追加して検査が「問題ID の台帳」で止まることはありません（増えるのは自由）。台帳を最新にするには `python3 tools/audit_data.py --write-golden`
- 数式は `$...$` と `\[...\]`、文章の `enumerate`・`itemize`・`tabular`・`\textbf`・`\fbox` などは自動で変換します。難易度は 0=基礎 〜 5=数学探究。「頻出度」列（1〜3、または 低・中・高。旧名「教育的価値」も可）は空欄なら自動判定（content/values.json）を使う 「解法」列（解法カードの名前か ID を読点区切り）に書いた問題は、タグからの自動の結びつきの代わりにその指定を使う（先頭が主な解法。`主な解法なし` と書くと主な解法を空にする）。
- 問題セットを作るとき：`content/collections/` に既存のファイルをまねて JSON を置き、`python3 tools/build_app_data.py`。問題ID の並びがそのまま出題順
- タグの言い換えをまとめるとき：`content/tags.json` の該当タグの `aliases` に別の表記を足して `python3 tools/build_app_data.py`
- 前の方法（Excel → data/ を直接）に戻すとき：`python3 tools/import_xlsx.py Lemma問題管理表.xlsx data --legacy`

### 入力用の答え（T列）

アプリの自動採点は「入力用の答え」列を正とします。書き方は管理表の「使い方」シートにあります。要点：

```
(1) $c_4$：1 ; $c_3$：0          ← 小問ごとに1行、欄は「 ; 」、ラベルは全角「：」
(2) {(10, 60), (28, 42)}        ← { } は順不同、( ) は順序あり
(3) -16<k<9                     ← 範囲（または・かつ・なし・すべての実数）
(4) 場合分け{ p<=1/2 → 2p+1 | p>1/2 → 2-2p }
(5) 証明                         ← 証明・図示・記述 は自己採点
```

空欄の問題は従来どおり記述式（紙に解く → 答え合わせ → 自己採点）。編集したら検査してください：

```sh
python3 tools/import_xlsx.py Lemma問題管理表.xlsx
node tools/check_answers.mjs data   # 入力用の答えが読めるか・自己整合するか
node tools/check_katex.cjs          # 数式がすべて描画できるか
```

新しい問題をまとめて作ったときは、管理表に入れる前に `python3 tools/validate_new.py 新しい問題.json` で検査できます（書式・KaTeX・入力用の答え・答え列との SymPy 照合・既存問題との重複）。

`tools/build_input_answers.sh` は、「答え」列（LaTeX）から入力用の答えを自動で下書きし、SymPy で元の答えと一致するか照合する一式です（初回の一括作成に使用）。

### 問題の図（content/figures.json・管理表の「図の式」列）

問題文の数式から、グラフに描ける式を `tools/figure_candidates.py` が取り出し、`tools/make_figures.mjs` がアプリと同じ解析器で確かめて選びます（`import_xlsx.py` が自動で実行）。

手で図を作りたい問題は、管理表に **「図の式」** 列を足して書きます（自動の図より優先）。1行に1つの式で、先頭に次の行を書けます。

```
モード：平面              ← 平面（省略時）・空間・複素数平面（ベクトルは平面・空間にそのまま書ける）
表示：答え合わせのあと    ← 省略すると、問題文が「図示せよ」「軌跡」などなら答え合わせのあと
A=(0,0)
B=(4,0)
C=(1,3)
p=A+t(B-A), 0<=t<=1
```

### 選択式の選択肢（content/choices.json）

選択肢は「入力用の答え」から `tools/make_choices.mjs` が決まった手順で作ります（AIではないので、何度実行しても同じ）。正解の書き方の数字を1つ変える・符号を変える・不等号の等号を付け外しする などで候補を作り、アプリの採点で不正解になること・候補どうしが重ならないこと・√4 や 2/4 のような不自然な形でないことを確かめて3つ選びます（3つ目は誤答をさらに変えたものにして、正解だけが「真ん中」に見えないようにしています）。

```sh
node tools/make_choices.mjs        # content/choices.json を作り直す（import_xlsx.py も自動で実行する）
python3 tools/build_app_data.py    # data/ に反映
```

管理表に列を足す必要はありません。入力用の答えを直した問題は、上の2行で選択肢も作り直されます。

### 弟テスト記録

設定 →「テスト記録の書き出し」で CSV を書き出せます（日付・問題ID・科目・分野・難易度・正誤・所要時間・手応え・どこで詰まったか・感想）。手応えは 1=手が出ない 〜 5=余裕。「判定がおかしい？」を押した欄は感想列に残ります。

## アカウントと同期（Supabase）

- 接続先は `js/config.js`（Project URL と Publishable key。公開してよい値だけ。Secret key は書かない）。空にすると同期の機能は出ない
- データベースの準備は `supabase/schema.sql` を SQL Editor で1回実行する（1人1行の表 `lemma_state` と、退会用の関数）
- ログインはメールの **コード**（iPhone のホーム画面アプリは Safari と保存領域が別なので、リンクではなくコードを入れる方式）。
  Supabase の Authentication → Emails の「Magic link」と「Confirm signup」の本文に `{{ .Token }}` を入れておく
- 記録の合わせ方：解答の記録は両方を足し合わせ、復習の予定は問題ごとに新しい方、設定は最後に変えた方（`js/sync.js` の `mergeState`）。2台が同時に書いても、版番号で取り直して合わせ直す
- Supabase の標準のメール送信は、プロジェクトのメンバーのアドレスにしか送れず、1時間に数通まで。ほかの人に使ってもらうときは Authentication → Emails → SMTP Settings で外部のメール送信サービスを設定する

## 公開する（配信用の dist/）

リポジトリは非公開にし、**アプリが動くのに必要なファイルだけ**を配信します。GitHub Pages はリポジトリ全体（`content/`・`tools/`・`tests/` も）を配信してしまい、無料プランでは非公開のリポジトリから配信できないため使いません。

```sh
python3 tools/build_dist.py        # dist/ を作る（index.html・privacy.html・terms.html・sw.js・css/・js/・vendor/・icons/・data/ だけ）
```

- `dist/_headers`：CSP などのセキュリティヘッダー（Cloudflare Pages の書式）。外部のスクリプトを読めないようにする。
  `script-src` の `'unsafe-eval'` は、`js/parser.js` が式を関数にする（`new Function`）ために必要
- `dist/robots.txt`：検索・収集ツールに読ませない。アプリの HTML にも `noindex`
- 配信してはいけないもの（`content/`・`tools/`・`.py`・`.md` など）が入っていたら、`build_dist.py` が失敗する
- `node tests/e2e_dist.mjs`：dist を CSP つきで配信して、採点・グラフ・KaTeX が動くこと、`content/` などが取れないことを確かめる

### Cloudflare Pages に自動で配置する

1. Cloudflare で Pages のプロジェクトを作る（Git 連携ではなく「Direct Upload」）。独自ドメインを付ける
2. GitHub のリポジトリの Settings → Secrets and variables → Actions に登録：
   Variables `CF_PAGES_PROJECT`（プロジェクト名）、Secrets `CLOUDFLARE_API_TOKEN`（Pages の編集権限だけ）・`CLOUDFLARE_ACCOUNT_ID`
3. 以後、main に push すると、検査が通ったときだけ dist/ が配置される（`.github/workflows/ci.yml`）
4. Cloudflare の Security → WAF → Rate limiting で、`/data/` への短時間の大量アクセスを制限する（例：同じ IP から 10秒に 60回まで）
5. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

更新したときは `sw.js` の `VERSION` を上げると、端末のキャッシュも入れ替わります。
URL（ドメイン）を変えると、ログインしていない人の端末の記録は新しい URL から見えなくなります（記録はブラウザの中で URL ごとに分かれるため）。
移る前に、設定 →「学習記録のバックアップ」で書き出し、新しい URL で読み込んでもらってください（ログインしている人は、新しい URL でログインすれば戻ります）。

## 問題を追加する

`js/content.js` の `PROBLEMS` に追記します。数式は `$...$`（KaTeX）。

```js
{
  id: 'q62', cards: ['sixth'], level: 2, type: 'num',
  q: String.raw`放物線 $y=x^2-1$ と $x$ 軸で囲まれた部分の面積を求めよ。`,
  ans: '4/3',
  hints: ['…', '…', '…'],
  sol: String.raw`…`,
  graph: ['y=x^2-1', 'x^2-1<=y<=0'],
},
```

| type | 答え方 | 判定 |
| --- | --- | --- |
| `num` | 数（`14/3`, `e^2`, `pi/4` も可） | 値が一致 |
| `expr` | 文字式 | `vars` の範囲で乱数を代入して一致 |
| `nums` | カンマ区切りの数 | 順不同で一致 |
| `choice` | 選択肢（`choices[0]` が正解） | 表示時にシャッフル |
| `sketch` | グラフを指で描く | 本物と重ねて自己評価 |

`cards[0]` がその問題の主な解法です。新しい解法カードは `CARDS` に追加し、`pre` に前提カードを書きます。

## 設計の根拠

- 想起練習・分散学習：Dunlosky et al. (2013), *Psychological Science in the Public Interest*
- 交互練習：Rohrer et al. (2020), *Journal of Educational Psychology*（中1・787人の無作為化試験）
- 答えを出さないAI支援：Bastani et al. (2025), *PNAS*

入試発展・数学探究レベルでの効果は未検証です。記録データ（書き出しJSON）を使って、自分で効果を確かめることを想定しています。
